# CreationOfASmallApp
A simple, interactive cross-platform mobile application that demonstrates dynamic UI updates based on user interaction. The application allows users to step through a sequence of button clicks to reveal a personalized message and rich visual content.

# IDE 
Visual Studio 2022
# Framework
.NET MAUI/Xamarin
# Language 
C#

# How to run app
1. Open project folder in Visual Studio 2022.
2. Ensure you have the .NET Multi-platform App UI development workload installed.
3. Select your target framework/emulator from the top toolbar dropdown(e.g., Android Emulator 'pixel_7_-api_33').
4. Press F5 of click the *START* to build and launch the application.
